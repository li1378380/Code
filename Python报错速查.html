Python 常见报错 速查

看到报错先别慌——按下面三步走，八成能自己定位。
第 1 步：看第一行

错误类型，如 NameError / TypeError。先知道是「哪一类」病。

第 2 步：看最后一行

具体信息，如 name 'x' is not defined。它直接告诉你哪里出了问题。

第 3 步：看行号与 Did you mean

报错里 line 25 就是出错的那行；「Did you mean」是在提示你拼写相近的名字。

SyntaxError 语法错误
代码「读不通」：括号/引号没配对、用了中文符号（，（）“”）、该有冒号没有。
print("hello"   # 少右括号
SyntaxError: '(' was never closed
修法：对着行号检查括号、引号、冒号，确认输入法是英文半角。
IndentationError 缩进错误
Python 靠缩进划分代码块：缩进层级不对，或者空格和 Tab 混用。
  print(1)
  # 前面多两个空格
IndentationError: unexpected indent
修法：同一层代码缩进必须一致；VS Code 里把 Tab 换成空格。
NameError 名字未定义
用了一个没定义过的变量/函数，最常见的是拼写不一致（多一个字母、少一个字母、大小写不同）。
print(popped_motorcycles)
NameError: name 'popped_motorcycles' is not defined.
Did you mean: 'popped_motorcycles'?
修法：逐字对比定义处和使用处；名字要完全一致。
TypeError 类型错误
对类型做了不支持的操作：字符串和数字相加、函数参数个数/类型不对、对 None 调用。
print("年龄：" + 20)
TypeError: can only concatenate str (not "int") to str
修法：转类型——print("年龄：" + str(20))，或用 f-string。
IndexError 索引越界
访问列表中不存在的下标。列表有 3 个元素时，最大下标是 2。
motorcycles = ["honda", "yamaha"]
print(motorcycles[2])
IndexError: list index out of range
修法：检查下标是否超过 len(list) - 1。
KeyError 键不存在
字典里取一个不存在的键。
person = {"name": "Li"}
print(person["age"])
KeyError: 'age'
修法：用 person.get("age", 默认值)，或先判断键是否存在。
ValueError 值不合法
类型对了、值不对：比如 int("abc")——要数字，给了字母。
int("abc")
ValueError: invalid literal for int() with base 10: 'abc'
修法：先确认字符串里是纯数字，或捕获异常处理。
AttributeError 属性/方法不存在
对象没有这个属性或方法：类名拼错（append 写成 apend）、字符串没有某方法。
motorcycles.apend("ducati")
AttributeError: 'list' object has no attribute 'apend'
修法：检查方法名拼写，或确认这个类型有没有该方法。
ZeroDivisionError 除以零
分母为 0，数学上不成立。
print(10 / 0)
ZeroDivisionError: division by zero
修法：除之前判断分母不为 0。
ModuleNotFoundError 模块找不到
import 的模块没装，或名字拼错。
import requests
ModuleNotFoundError: No module named 'requests'
修法：pip install 模块名；先确认名字没拼错。

报错里的高频英文（认脸就行，不用背）

英文意思常见场合
not defined没有定义NameError：变量名拼错/没赋值
out of range超出范围IndexError：下标越界
invalid无效的ValueError：值不合法
unsupported operand不支持的操作数TypeError：类型不能这么运算
unexpected意外的SyntaxError：多出来的符号
expected期望SyntaxError：少了该有的东西
missing缺少参数/括号没给全
has no attribute没有这个属性AttributeError：方法名拼错
never closed从未闭合括号/引号没配对
Did you mean你是不是想写拼写相近提示，照着抄就对了
遇到不认识的报错：截图丢给女儿，或把最后一行复制过来问——别自己干瞪眼。
